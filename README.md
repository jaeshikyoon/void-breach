# VOID//BREACH

[Play VOID//BREACH on GitHub Pages](https://jaeshikyoon.github.io/void-breach/)

`VOID//BREACH`는 브라우저에서 실행되는 2D 아이소메트릭 액션 서바이벌 게임입니다. React가 메뉴와 HUD를 담당하고 PixiJS가 전투 월드, 유닛, 투사체와 이펙트를 렌더링합니다. 진행도는 생존 시간이 아니라 **디렉터가 투입한 몬스터 수**로 결정됩니다.

## 게임 흐름

- 한 번의 작전에서 일반 몬스터를 정확히 200체 투입합니다.
- 몬스터는 한 마리씩 나오지 않고, 현재 생존 수가 목표치보다 낮을 때 구간별 규모의 증원 배치로 들어옵니다.
- 40·80·120·160·195번째 개체는 엘리트입니다.
- 200번째 투입 후 일반 증원이 끝나고 최종 보스가 등장합니다.
- 소환수가 만든 적과 보스의 추가 소환은 200체 카운트 및 일반 경험치 지급 대상에서 제외됩니다.
- 캠페인은 **STAGE 1~20**으로 구성됩니다. 이전 스테이지를 별 1개 이상으로 클리어하면 다음 스테이지가 열리며, 후반으로 갈수록 일반 적과 보스의 체력·공격력·이동 속도가 단계적으로 상승합니다.
- 승리 시 남은 HP가 100%면 별 3개, 50% 이상이면 별 2개, 그 미만이면 별 1개를 받습니다. 스테이지별 최고 별 기록만 보존됩니다(총 60개).
- 20개 스테이지는 5개 전선으로 나뉘며, 진행에 따라 적 편성이 기존 12종에서 신규 8종을 포함한 총 20종까지 확장됩니다. 각 전선은 철갑 파쇄자, 역병 군체의식, 폭풍 감시자, 공허 모체, 균열 군주 중 하나를 전용 보스로 사용합니다.
- 레벨 업 때 액티브 스킬 또는 패시브 강화 카드 중 하나를 선택하며, 한 작전에서 액티브 스킬은 최대 3개까지 장착합니다.

| 투입 번호 | 목표 생존 수 | 배치 규모 | 주요 변화 |
| --- | ---: | ---: | --- |
| 1–30 | 20 | 4–6 | 감염체, 추격체 |
| 31–75 | 35 | 5–8 | 사수, 폭발체 합류 |
| 76–125 | 50 | 6–9 | 방패병, 거구, 원소 원거리 적 합류 |
| 126–170 | 65 | 7–10 | 지원·매복·소환 역할 합류 |
| 171–200 | 75 | 8–12 | 전체 조합, 최종 압박 |

동시 생존 상한은 디렉터 몬스터 90체, 소환 몬스터 15체, 엘리트 3체입니다.

## 실행

최근 Node.js LTS(권장: 20 이상)와 npm이 필요합니다.

```bash
npm install
npm run dev
```

개발 서버가 출력한 로컬 주소를 브라우저에서 여십시오. 배포 빌드와 검증 명령은 다음과 같습니다.

```bash
npm run typecheck
npm run test:run
npm run test:e2e
npm run build
npm run preview
```

`npm test`는 감시 모드로 Vitest를 실행합니다. 현재 단위 테스트는 스폰 디렉터, 공격 슬롯 조정, 피해 계산, 경험치, 시드 RNG, 상태 전이, 업그레이드 카드 규칙을 다룹니다. `test:e2e`는 설치된 Chrome을 사용해 시작 화면, 최초 20체 배치, 일시정지 전환, 모바일 가로 조작 UI를 검증합니다.

## 조작

### PC

| 입력 | 기능 |
| --- | --- |
| `WASD` 또는 방향키 | 이동 |
| 마우스 이동 | 조준 |
| 마우스 왼쪽 버튼 유지 | 기본 사격 |
| `Space` 또는 마우스 오른쪽 버튼 | 대시/회피 |
| `Q`, `E`, `R` | 장착 스킬 1–3 |
| `Esc` | 일시정지/재개 |
| `1`, `2`, `3` | 레벨 업 카드 선택 |

### 모바일/태블릿

- 왼쪽 가상 조이스틱으로 이동합니다.
- `FIRE`를 누르고 있는 동안 기본 사격을 이어갑니다. 포인터 조준이 없으면 가까운 적을 기준으로 조준을 보정합니다.
- 오른쪽 회피 버튼과 최대 3개의 스킬 버튼을 사용합니다.
- 세로 화면에서는 전투를 멈추고 가로 모드 안내를 표시합니다.

## 구조

```text
src/
├─ game/core/       순수 전투 규칙, 스폰·경험치·피해·상태 머신
├─ game/data/       몬스터 20종, 액티브 스킬 10종, 선택 가능한 패시브 강화 15종
├─ game/runtime/    PixiJS 월드, 고정 스텝 루프, AI, 충돌, 카메라, VFX
├─ game/services/   입력, Web Audio 효과음, 저장, 생명주기, 적응형 품질
├─ ui/              React HUD, 시작·일시정지·레벨 업·결과 화면
└─ styles/          데스크톱/터치/가로 화면 반응형 스타일
```

핵심 시뮬레이션은 60 Hz 고정 스텝으로 동작합니다. 공간 해시, 투사체·경험치 오브 풀링, 화면 밖 컬링 여유값, 공격 슬롯 조정으로 다수 개체 상황을 처리합니다. 최고 기록, 스테이지별 별, 설정은 IndexedDB에 저장하며, 사용할 수 없는 환경에서는 현재 세션의 메모리 저장소로 자동 전환합니다.

## 그래픽 품질과 브라우저 조건

기본값 `auto`는 CPU 코어 수, 기기 메모리, 터치 여부, 모션 감소 설정과 실제 프레임 성능을 보고 `high`, `balanced`, `low` 사이를 히스테리시스로 조정합니다.

| 모드 | 최대 파티클 | 피해 숫자 | 트레일 밀도 | AI 갱신 간격 | 기타 |
| --- | ---: | ---: | ---: | ---: | --- |
| High | 700 | 80 | 100% | 매 스텝 | 소프트 섀도, 화면 흔들림 |
| Balanced | 380 | 48 | 65% | 2스텝 | 화면 흔들림 |
| Low | 180 | 24 | 35% | 3스텝 | 소프트 섀도·화면 흔들림 비활성 |

- 최신 Chromium, Firefox, Safari 등 WebGL과 Pointer Events를 지원하는 브라우저를 권장합니다.
- ES 모듈과 절대 자산 경로를 사용하므로 HTML 파일을 직접 열지 말고 Vite 또는 정적 웹 서버를 통해 실행해야 합니다.
- 모바일 브라우저 정책상 효과음은 첫 클릭/탭 이후 활성화됩니다.
- 모바일은 가로 화면을 기준으로 설계했습니다. 저사양 기기에서는 자동 품질 또는 Low 모드를 권장합니다.
